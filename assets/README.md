# Project Assets

This directory stores visual media, hardware assembly photographs, circuit schematics, and demonstration GIFs for the repository documentation.

### Recommended File Naming
- `hardware_assembly.jpg`: Full photo of the assembled 5-DOF robotic arm.
- `wiring_diagram.png`: Schematic of ESP32, PCA9685, SMPS, and INMP441 connections.
- `web_dashboard.png`: Screenshot of the browser-based control dashboard.
- `voice_studio.png`: Screenshot of the phone/web offline voice studio.
- `demo_working.gif`: Animated demonstration showing voice command response (e.g. "grab", "up", "sleep").
