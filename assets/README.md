# Project Assets

This directory stores visual media, hardware assembly photographs, circuit schematics, and demonstration GIFs for the repository documentation.

### Media Slots
- `hardware_assembly.jpg`: Full photo of the assembled 5-DOF robotic arm.
- `demo_working.gif`: Animated demonstration showing voice command response (Wake, Sleep, Direction).
- `demo_motion.gif`: Second animated demonstration showing arm motion routine (Pick, Place, Gripper action).
- `wiring_diagram.png`: Complete circuit wiring schematic.
